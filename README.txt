# Eman 11.11 ❤️

## التشغيل
1. فك ضغط الملف كاملًا في مجلد واحد.
2. أعد تسمية ملف الأغنية بالضبط إلى: eman-song.mp3
3. ضع ملف eman-song.mp3 بجانب index.html في نفس المجلد (ليس داخل مجلد فرعي).
4. افتح index.html واضغط «افتحي عالمنا».

مهم: تشغيل الصوت يبدأ بعد الضغط على زر البداية لأن المتصفحات تمنع التشغيل التلقائي قبل تفاعل المستخدم. عند رفع الموقع للإنترنت، ارفع ملف الأغنية مع بقية الملفات في نفس المجلد.
